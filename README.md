# StudyFinder

Aplicativo web para ajudar estudantes a encontrar e organizar grupos de estudo.

## AA1

Telas desenhadas, sem lógica:


cadastro.html - Cadastro (nome, curso, ano de ingresso) 

index.html - Dashboard com os grupos do usuário 

busca-grupos.html - Busca de grupos de estudo 

criar-grupo.html - Criação de grupo (matéria e professor) 

grupo.html - Grupo e agenda de sessões 

styles.css - Estilos compartilhados (identidade visual e responsividade) 

## Como testar

Abra `index.html` com um navegador web.
